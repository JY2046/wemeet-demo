# 会意 WeMeet

为 Ether Coffee 听障咖啡师设计的双向无障碍服务 Demo。

会意把咖啡服务中原本依赖声音的关键时刻，转换为双方看得见、可确认、能回应的沟通：

- 顾客可通过点选卡片、语音转文字或直接打字表达需求；
- 订单修改以视觉方式突出并由双方确认；
- 制作中通过需求卡与大字回复完成双向沟通；
- 以视觉方式提醒取餐；
- 支持现场体验反馈。

## 在线体验

GitHub Pages 启用后访问：<https://jy2046.github.io/wemeet-demo/>

## 本地运行

```bash
python3 -m http.server 4173
```

打开 <http://localhost:4173>。

> 当前为共创验证原型，部分语音与 AI 能力使用演示数据，功能将依据 Ether Coffee 咖啡师的真实反馈继续迭代。
